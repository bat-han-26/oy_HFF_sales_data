# oy_HFF_sales_data

올리브영(Olive Young) 건강기능식품(HFF, Health Functional Food) 매출 데이터 취합 및 브랜드 분석 프로젝트입니다.

## 프로젝트 구성

| 파일 | 설명 |
|---|---|
| `oy 매출 데이터 취합.xlsx` | 원본 매출 데이터 (브랜드/상품/일자별 매출·수량·랭킹) |
| `올리브영_매출분석_리포트.md` | 브랜드 단위 매출 분석 결과 리포트 |
| `README.md` | 프로젝트 개요 (본 문서) |

## 데이터 구조 (xlsx 시트)

| 시트 | 내용 |
|---|---|
| `기간정의` | 평시·세일전주·이번/직전 올영세일의 기간 및 일수 정의 |
| `조인_일자상품` | 일자×상품 단위 원천 데이터 (매출/판매수량/주문수/구매자수/랭킹) |
| `평시` | 평시(2026-04-22~05-23, 32일) 상품별 집계 |
| `세일전주` | 세일전주(2026-05-24~05-30, 7일) 상품별 집계 |
| `이번올영세일` | 6월 세일(2026-05-31~06-06, 7일) 상품별 집계 |
| `직전올영세일` | 3월 세일(2026-03-01~03-07, 7일) 상품별 집계 |
| `세일비교(이번vs직전)` | 6월 vs 3월 세일 상품별 매출 증감 비교 |

> 주의: 직전세일(3월)은 랭킹 데이터가 없어(CSV 수집이 4/22부터) 매출 비교만 유효합니다.

## 분석 요약

- 올영세일은 일평균 매출을 평시의 **3.6~3.8배**로 끌어올리는 핵심 이벤트.
- **세일전주는 평시보다 매출이 낮음(0.77배)** — 세일 대기 수요로 인한 구매 연기 현상.
- 이번 6월 세일 1위 브랜드는 **푸드올로지**, 평시 1위는 **오쏘몰**.
- 3월→6월 절대 증가액 1위는 **덴프스(+0.66억)**, 중형 브랜드(생활약속·온리추얼·칼로 등) 100%대 약진.
- **올더베러**는 3월→6월 -38% 부진. 주력 SKU(올인원 비타민 미네랄 구미 60구미) 단일 품목의 -97.5% 붕괴가 주원인.
